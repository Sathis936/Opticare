OptiCare — Documentation

Optical Store & Eye Care HTML Template · Bootstrap 5 · Vanilla JS

Overview

OptiCare is a clean, modern and fully responsive HTML template built for optical stores, opticians and eye-care clinics. It ships with 24 frontend pages and 17 admin dashboard pages, and is built entirely with HTML5, Bootstrap 5, vanilla JavaScript and pure CSS — no build tools or backend required.

Open any .html file directly in your browser or serve the folder with any static server.

Key Features

  • 24 frontend pages + 17 admin pages
  • Bootstrap 5.3 grid, components & utilities
  • Dark / Light mode with localStorage persistence
  • RTL / LTR direction switcher
  • Fully responsive (320px → 1920px)
  • WAI-ARIA friendly, semantic markup
  • Chart.js dashboards & reports
  • Swiper.js sliders, Flatpickr date pickers
  • No jQuery, no external dependencies except the bundled libraries

Installation

No build step required. To preview locally:

  1. Copy the opticare/ folder anywhere on your machine.
  2. Double-click index.html, or run a static server, e.g.:
    npx serve opticare
# or
python -m http.server 8000 --directory opticare
  3. Navigate to http://localhost:8000.
Some demo screenshots or external fonts load from Google Fonts — an internet connection is required the first time those fonts are fetched.

<link rel="stylesheet" href="assets/css/bootstrap.min.css">
<link rel="stylesheet" href="assets/css/bootstrap-icons.min.css">
<link rel="stylesheet" href="assets/css/google-fonts.css">
<link rel="stylesheet" href="assets/css/swiper-bundle.min.css">
<link rel="stylesheet" href="assets/css/flatpickr.min.css">
<link rel="stylesheet" href="assets/css/style.css">
<link rel="stylesheet" href="assets/css/responsive.css">
<link rel="stylesheet" href="assets/css/dark.css">
<link rel="stylesheet" href="assets/css/rtl.css">
<link rel="stylesheet" href="assets/css/flatpickr-dark.css">
  • style.css — all components: header, hero, cards, forms, footer, auth, booking, blog, contact, and the whole .admin-* section (from ~line 4160).
  • responsive.css — breakpoint overrides (1200/992/768/576/375/320).
  • dark.css — [data-theme="dark"] overrides.
  • rtl.css — [dir="rtl"] overrides.

Dark Mode & RTL

The <html> tag carries the state:

<html lang="en" data-theme="light" dir="ltr">

Use these two buttons anywhere (theme.js wires them up automatically):

<button type="button" data-theme-toggle aria-label="Toggle dark mode"><i class="bi bi-moon-stars"></i></button>
<button type="button" data-dir-toggle aria-label="Toggle RTL"><i class="bi bi-arrow-left-right"></i></button>

State is persisted in localStorage under opticare_theme and opticare_dir. Custom events opticare:theme and opticare:dir are dispatched after every change so scripts (e.g. Chart.js recoloring) can react.

Brand Colors

All colors are CSS custom properties defined in style.css. Edit them once and the whole template updates:

:root {
  --primary: #0d6efd;   /* main brand blue */
  --secondary: #6ee7f5; /* accent cyan */
  --dark: #0b172d;      /* headings / dark surfaces */
  --text: #3c4757;      /* body text */
  --muted: #6b7a90;     /* muted text */
  --border: #e6ebf2;    /* hairlines */
  --bg: #f6f9fc;        /* page background */
  --card-bg: #ffffff;   /* cards */
  --radius: 14px;
  --box-shadow: 0 10px 30px rgba(11, 23, 45, 0.07);
}
Dark-mode counterparts live in dark.css under [data-theme="dark"]. Keep every component using variables so the theme swaps cleanly.

theme.js — Dark / RTL Switcher

Load theme.js before main.js. It exposes a global window.OptiCareTheme with getTheme(), getDir(), setTheme(), setDir() and persists both choices in localStorage.

// Read current state anywhere
var theme = window.OptiCareTheme.getTheme();
var dir = window.OptiCareTheme.getDir();

Admin Shell

Every admin page uses the same layout:

<body class="admin-body">
  <div class="admin-wrapper">
    <aside class="admin-sidebar">
      <div class="sidebar-head"> ... logo + toggle ... </div>
      <div class="sidebar-scroll">
        <div class="sidebar-section">
          <span class="sidebar-label">Overview</span>
          <ul class="sidebar-nav">
            <li class="nav-item"><a class="nav-link active" href="index.html">...</a></li>
          </ul>
        </div>
        ...
      </div>
    </aside>
    <div class="admin-main">
      <header class="admin-topbar"> ... </header>
      <main class="admin-content"> ... page content ... </main>
    </div>
  </div>
  <div id="sidebarBackdrop"></div>
</body>
  • Sidebar is fixed and 264px wide (--sidebar-w); the main area is offset with margin-inline-start.
  • Desktop: [data-sidebar-toggle] toggles the sidebar-collapsed class on body.
  • Mobile (≤992px): the same button toggles sidebar-open, sliding the sidebar in as an off-canvas panel. Clicking #sidebarBackdrop closes it.
There is no CSS for the backdrop in style.css, so each admin page includes a small inline <style> block styling #sidebarBackdrop as a fixed overlay shown when .sidebar-open is present. Keep it when you duplicate a page.
main.js only auto-highlights links inside .main-nav / .offcanvas-nav. The admin sidebar does not auto-highlight — hard-code class="nav-link active" on the current page’s link.

Admin Data Tables

One generic engine powers every admin table. Each table gets a unique name and matching controls:

<table class="table table-admin" data-table="products"> ... </table>
<input  data-table-search="products">
<select data-table-status="products"></select>   <!-- option values must match data-status on badges -->
<select data-table-size="products"></select>
<span   data-table-info="products"></span>
<ul     data-table-pagination="products"></ul>
  • Search filters rows by text content.
  • Status filter matches the first .status-badge[data-status] in a row.
  • Pagination + "Showing X-Y of Z" info update automatically.

More Admin Controls

Delete confirmation

Any element with data-delete opens the Bootstrap modal #deleteModal (include it on every page that uses delete buttons) and shows a toast.

Image upload preview

Support & Customization

  • To change content, edit the HTML directly — it is plain, commented sections.
  • To restyle, edit CSS variables in style.css (see Brand Colors).
  • To extend JS behavior, follow the attribute-hook pattern in main.js.
  • Test at breakpoints: 320, 375, 390, 576, 768, 992, 1200, 1440, 1920.
